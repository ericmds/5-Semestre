### Cascata
* Cliente só tem acesso do produto no final do desenvolvimento, mas é o um produto completo
* Um problema é que o processo de teste, acontece pouca vezes, somente na contrução

### O modelo V
* Possui uma etapa de testes para cada etapa do desenvolvimento
* Os testes são criados no inicio do projeto, ou seja, ja sabemos os testes que teremos que fazer no inicio do projeto, mas serão executados no final do desenvolvimentom ou seja, quando o software executável
