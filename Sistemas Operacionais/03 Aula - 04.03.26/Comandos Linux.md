* pwd (ver diretorio atual)
* ls (mostrar diretorios)
* ls -l
* man ls
* mkdir (Criar um diretório/pasta)
* cd nomeDaPasta (Acessar o diretório)
* vi nomeArquivo (outra forma de criar arquivo)
    * i - para inserir texto
    * o abre 1 linha e insere texto
    * esc :w - grava
    * esc :wq - sair
    * esc :q! - sair sem gravar
* cp diretorioOriginal ./diretorioQueVaiCopia
* mv (mover ou renomear)
* cd .. (voltar)
* rm nomeArquivo (apaga)

# Exemplo
* mkdir SO
  * Criando diretorio SO
* mv arquivo.txt SO
  * Movendo o arquivo.txt da AulaTeste para SO
* cd SO
  * Entrar no diretório SO 
* ls
  * Verificar arquivos no SO
* cd..
  * Voltando para AulaTeste
* mv teste.txt carta.txt
  * Renomeando teste.txt para carta.txt
* rm carta.txt
  * Removendo carta.txt
* cd SO
  * entrando no diretorio SO
* rm *
  * Apagando tudo no diretorio SO
* cd ..
  * Voltando para AulaTeste
* rmdir SO
  * Apagando diretorio SO (Só funciona se não tiver nada no diretório)
